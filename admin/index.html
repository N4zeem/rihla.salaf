އެޑްމިން ޕެނަލް

ވަދެލުމަށް ގިޓްހަބް ޓޯކަން ޖައްސަވާ

ޓޯކަން ހަދާނީ ކިހިނެއް؟
  1. github.com އަށް ލޮގިން ކުރައްވާ (ޖަމްޢިއްޔަތުއް ސަލަފް އޮގަނައިޒޭޝަނުގައި ހިމެނޭ އެކައުންޓަކުން).
  2. މި ލިންކް ހުޅުއްވާ: github.com/settings/tokens/new — ބޭނުންވާ ހުރިހާ ކަމެއް ކުރިން ލާފައި ހުންނާނެ.
  3. Expiration ބޭނުންފުޅު ގޮތަކަށް ބަދަލުކުރައްވާ (މިސާލަކަށް 90 days).
  4. ތިރިއަށް ގޮސް Generate token އަށް ފިއްތަވާ.
  5. ghp_ އިން ފެށޭ ޓޯކަން ކޮޕީކޮށް މަތީގައިވާ ފޮށީގައި ޖައްސަވާ.
